## Isi repository

| File | Fungsi |
|------|--------|
| `index.html` | Struktur halaman |
| `style.css` | Tampilan (external CSS) |
| `images/papuma.jpg` | Foto pantai |

## Konsep CSS yang dipakai

- External CSS
- Selector elemen, class, dan pseudo-class (`:hover`, `:nth-child`)
- Box model: margin, padding, border
- Flexbox (header)
- CSS Grid (hero)
- Styling tabel, daftar, dan gambar (`object-fit`)
- Media query untuk tampilan HP
